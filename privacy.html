Política de privacidad de keluaBot

Última actualización: 12 de noviembre de 2026

keluaBot es un bot de Telegram que, a partir de una foto de una prenda de ropa, genera una imagen publicitaria con un modelo y un fondo. Esta política explica qué datos se utilizan y cómo se tratan.

1. Datos de usuario de Google a los que se accede

La aplicación solicita únicamente los permisos básicos de Google: dirección de correo electrónico, información básica del perfil e identificador de la cuenta. Se utilizan exclusivamente para autenticar la cuenta de Google y conectarla con la plataforma de automatización (n8n) que hace funcionar el bot. No se accede al contenido de Gmail, Drive, Calendar ni a otros servicios de Google.

2. Uso de los datos

Los datos de Google se usan solo para autenticar la conexión y permitir que el bot funcione. No se utilizan para publicidad, perfilado ni ninguna otra finalidad.

3. No se venden ni se comparten

Los datos de usuario de Google no se venden, no se ceden y no se comparten con terceros, salvo que sea necesario para el funcionamiento técnico de la conexión o lo exija la ley.

4. Almacenamiento, protección y conservación

Los datos de autenticación se guardan de forma cifrada en la plataforma de automatización, con acceso restringido al responsable. Se conservan solo mientras la conexión esté activa y se eliminan al revocar el acceso o al solicitarlo.

5. Eliminación de datos y revocación del acceso

Puedes revocar el acceso de keluaBot en cualquier momento desde https://myaccount.google.com/permissions. Para solicitar la eliminación de tus datos, escribe a javitvill12@gmail.com.

6. Política de datos de usuario de los servicios de API de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google por parte de keluaBot cumplirá la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado.
